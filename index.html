🦴 EquiVet Rx — App Desktop

O módulo de análise radiográfica roda como aplicativo desktop Windows (Streamlit), porque processa imagens DICOM pesadas e usa modelo de ML local (EfficientNet-B0).

Para abrir:

1. Vá em /Volumes/Centauro/EquivetIAOpus4/

2. Duplo-clique em EXECUTAR_PORTATIL.bat

3. O app abre em localhost:8501 no navegador

Para o Campo de Treinos (HITL), use CAMPO_TREINOS.bat (porta 8502).
